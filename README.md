# Blum AR Menu - dome version (v1)

Based on the Melt9 dome v30 (bigger dome, pizza raised,
top yellow circle removed, logo below the pizza).
Blum colours: red #E00102, light grey #E3E6EE, black #000000.
Glass dome capsule, silver ring, red glow ring around the
dome base, dark metal base, black BLUM logo plate below
the pizza, fixed AR label, Add to cart + Photo in AR,
self-hosted libs/ engine. iOS (Quick Look) + Android
(MindAR camera scan).

## IMPORTANT - dishes are placeholders for now
The 3 dishes in dishes.js are still the Melt9 pizzas
with their 3D models and photos, because Blum's menu
was not given yet. To make this a real Blum menu, send:
  1. Blum dish names + prices (3 dishes to start)
  2. A photo of each dish
  3. A 3D model of each dish (RealityScan, like Melt9)
  4. Blum phone / WhatsApp number
Then dishes.js + the dishes/ folder get swapped to
Blum's dishes, and the Melt9 pizza files are removed.
